# Organització del treball

Enunciat: https://github.com/optimisme/DAM-LlenguatgeMarques/blob/main/02-Web/17-TreballHTML.md

Les quinze tasques estan creades com a GitHub Issues: https://github.com/Yinhao7676/DAM1M04-ExerciciHTML/issues. Les tasques tècniques es vinculen a la Pull Request d’integració. La preparació tècnica no substitueix les aportacions reals dels dos integrants.

| Tasca | Criteri d’acceptació | Estat inicial |
| --- | --- | --- |
| 1. Preparar GitHub | Repositori, integrants, branques, Issues i PR | Repositori i branques creats; falta usuari i col·laboració de Diego |
| 2. Estructura | Cinc pàgines i recursos relatius | Implementada |
| 3. Identitat visual | Paleta, marca, Google Fonts, components | Implementada |
| 4. Header i menú | Menú compartit, pàgina activa, checkbox mòbil | Implementada |
| 5. Footer | Quatre xarxes, icones, hover, copyright a la dreta | Implementada |
| 6. Inici | Hero, nou disc, novetats, scroll, SVG i control | Implementada |
| 7. Música | Cinc àlbums, reproductor i pestanyes radio | Implementada |
| 8. Història | Biografia, sis fites, imatges i carrusel | Implementada |
| 9. Concerts | Sis concerts, estats, botons i tres filtres | Implementada |
| 10. Contacte | Dades demo, mapa i validació HTML5 | Implementada |
| 11. Animacions | Keyframes, transicions, transformacions, pausa | Implementada |
| 12. Responsive | Flexbox, dos breakpoints, botons i lectura | Comprovada a 320, 390 i 1440 px |
| 13. Revisió | Enllaços, accessibilitat i dos navegadors | Revisada; límits a VERIFICACIO.md |
| 14. Proxmox | Cinc pàgines accessibles i README actualitzat | Publicada i comprovada |
| 15. Entrega | Dues URL, contribucions reals i Moodle | Pendent dels integrants |

Proposta de repartiment per a aportacions posteriors: Yinhao revisa la composició, la música i les animacions; Diego revisa els continguts, els concerts, l’accessibilitat i les proves. Cada persona ha d’utilitzar el seu compte, la seva branca i una Pull Request.
